ARSITEKTUR & INTEGRASI

Kirim event dari pipeline CI/CD hanya dengan beberapa baris kode.

GoChat menyediakan SDK resmi dan endpoint webhook berkecepatan tinggi. Kirim hasil benchmark, status rilis container, atau alert insiden langsung ke channel tim Anda.

Multiplexed WebSocket Gateway
Satu koneksi TCP persisten menangani seluruh channel, indikator mengetik, dan presence anggota.
Penyimpanan Terpartisi Waktu
Pencarian teks instan pada jutaan pesan historis dengan partial index yang teroptimasi.
package main

import (
	"context"
	"time"
	"github.com/devspace-id/gochat-sdk"
)

func NotifyRelease(ctx context.Context) error {
	client := gochat.NewClient("gc_live_98f2a41c8b")

	return client.Channel("general").Send(ctx, &gochat.Message{
		Author: "Release Bot",
		Badge:  "CI/CD",
		Text:   "Deployment `api-gateway v2.14.0` selesai. Latensi P99: `19ms`.",
		CodeAttachment: &gochat.CodeBlock{
			Language: "sql",
			Content:  "SELECT count(*) FROM active_sessions WHERE region = 'ap-southeast-3';",
		},
		Timestamp: time.Now(),
	})
}
